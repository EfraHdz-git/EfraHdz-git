## How I build

- **Rules before models.** Deterministic code filters, validates and enforces limits; the model does the reading and reasoning.
- **Evidence or it does not ship.** Generated claims must cite a source record or a verbatim quote, and code removes anything unsupported.
- **Measure cost and quality.** Model choices are settled on real evaluation cases, with token, cache and cost tracking on every call.
- **A person decides what matters.** Sensitive actions and final decisions go through human approval gates.
